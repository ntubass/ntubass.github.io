# 用不到的檔案

這些是網站範本（ScrewFast）原本附的檔案，目前的網站用不到，先收在這裡。
網站建置與部署都不會讀這個資料夾；確定不需要的話，整個資料夾刪掉也沒關係。

| 檔案 | 原本的用途 | 為什麼用不到 |
| --- | --- | --- |
| `vercel.json` | 部署到 Vercel 時的安全性設定 | 網站部署在 GitHub Pages，不會讀這個檔案 |
| `FUNDING.yml` | GitHub 上的「贊助」按鈕設定（原本在 `.github/`） | 系學會網站不需要贊助按鈕 |
| `CODE_OF_CONDUCT.md` | 開源專案的貢獻者行為準則 | 這是系學會網站，不是開放外部貢獻的專案 |
| `README-ScrewFast範本.md` | 範本的英文說明文件 | 已換成新的中文 `README.md` |

另外也移除了四個沒有用到的套件：`@astrojs/starlight`（文件網站）、`gsap`（動畫）、
`clipboard`（複製按鈕）、`astro-vtbot`（頁面轉場）。需要的話可以用 `npm install 套件名稱` 裝回來。
